Liquid Flow overview

LiquidFlow is the non-custodial payment portal for Verse dApps. It accepts VERSE, fxVERSE and canonical USDC through generated-address checkout, finality-aware verification and signed webhooks.

Mainnet. LiquidFlow verifies supported token transfers on Ethereum, Polygon and Base. Use the documented token contracts and complete your own production security review before handling material value.

The non-custodial principle

This is the single rule the whole product is built around:

🔒 Liquid Flow can time and authorize, but never move funds. Your spend key is shown to you once and is never stored on our servers. If Liquid Flow were fully compromised, no user money could be taken.
  • Payments & fundraising: payments rotate across 10 merchant-owned wallets before merchant-approved consolidation.
  • Payroll: funds sit in a contract you own; our trigger key can only release a company-defined payout on or after its scheduled time, to the recipient you set.

How a payment works

  1. Request — your platform calls POST /api/payments; we return the merchant primary payment address.
  2. Pay — the payer sends VERSE, fxVERSE or USDC to that address on the selected supported mainnet.
  3. Confirm — our watcher verifies canonical token Transfer events at the required finality depth (also on-demand when you poll).
  4. Notify — an HMAC-signed webhook reaches your app; verify it and re-check payment status before releasing high-value goods.

Quickstart

Create a merchant, then a payment. Full details in the API Reference.

# 1. Create a merchant (returns an API key)
curl -X POST https://liquidflow-io.vercel.app/api/merchants \
  -H "Content-Type: application/json" \
  -d '{"name":"Acme","mode":"direct","chains":["eip155:1","eip155:137","eip155:8453"],"settle":"USDC","webhook":"https://acme.com/hook"}'

# 2. Create a payment (use the api_key from step 1)
curl -X POST https://liquidflow-io.vercel.app/api/payments \
  -H "Authorization: Bearer lf_live_..." \
  -H "Content-Type: application/json" \
  -d '{"amount":"1000000","asset":"USDC","chain":"eip155:137","label":"Order #1024"}'
# → { "deposit_address": "0x…", "status": "awaiting_payment", … }
